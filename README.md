# 💼 Know Your Worth: Tech Salary Estimator

A machine learning web application built with **Streamlit** and **Scikit-Learn** that predicts technology salaries based on user parameters using **Multiple Linear Regression**.

---

## 📌 Project Overview
This project predicts estimated tech compensation by analyzing key factors that impact compensation in the technology industry. 

### Features Considered:
* 🕒 **Years of Experience**
* 🎓 **Education Level** (Bachelor's, Master's, PhD)
* 🛠️ **Technical Skills Count**
* 📍 **Location** (Major Tech Hub vs. Standard/Remote)

---

## 🛠️ Machine Learning Details
* **Algorithm:** Multiple Linear Regression (`sklearn.linear_model.LinearRegression`)
* **Framework:** Streamlit for the user interface
* **Data Handling:** Pandas & NumPy
