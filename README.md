# 💼 Tech Salary Estimator — Predictive Analytics Engine

A machine learning web app that estimates technology salaries based on key career indicators, built with **Python**, **Scikit-Learn**, and **Streamlit**.

---

## 🚀 Overview
The **Tech Salary Estimator** uses multiple linear regression models trained on tech industry parameters (including years of experience, education level, technical skill count, and geographic location) to provide real-time salary predictions via an interactive UI.

---

## ✨ Key Features
* **Interactive Salary Prediction:** Dynamic input controls to evaluate expected compensation based on individual candidate profiles.
* **Multi-Factor Analysis:** Weighs factors like years of experience, technical skills, and role location.
* **Model Performance Metrics:** Integrates evaluation metrics ($R^2$ score, mean absolute error) to assess predictive performance.
* **Custom Streamlit Dashboard:** Clean interface designed for simple navigation and quick estimations.

---

## 🛠️ Tech Stack
* **Language:** Python
* **UI Framework:** Streamlit
* **Machine Learning:** Scikit-Learn (Linear Regression, StandardScaler)
* **Data Processing:** Pandas, NumPy
